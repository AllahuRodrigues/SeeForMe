# Third-party components and data: licences and what they mean for this repository

This repository's own code has no licence file yet (all rights reserved by the author until one is chosen). It uses,
ships or derives from the components below. `data/manifests/datasets.json` and `data/manifests/models.json` hold the
same information in machine-readable form (`python scripts/build_manifests.py`).

## Shipped in this repository

| component | where | licence | consequence |
|---|---|---|---|
| YOLO11n weights (Ultralytics), ONNX export | `web/public/models/yolo11n.onnx`, `models/export/yolo11n.onnx` | AGPL-3.0 (or an Ultralytics Enterprise licence) | serving the web app distributes the model: under AGPL-3.0 the source of the serving application must be offered to its users; closed-source or commercial use needs an Enterprise licence |
| YOLO11s weights (Ultralytics), ONNX export | `web/public/models/yolo11s.onnx` | AGPL-3.0 (or an Ultralytics Enterprise licence) | as for YOLO11n; the web app loads it on devices with WebGPU |
| ONNX Runtime Web | `web/public/ort/` | MIT | keep the copyright notice |
| Learned schedulers trained on EgoBlind | `models/egoblind*/` | derived from CC BY-NC 4.0 data | research and education only; cite EgoBlind |
| EgoBlind-tuned P-CACS weights | `configs/pcacs_egoblind.yaml` | derived from CC BY-NC 4.0 data | research and education only |
| EgoBlind-tuned P-CACS weights (superseded) | `results/egoblind/exploratory_2026-10-08/pcacs_egoblind*.yaml` | derived from CC BY-NC 4.0 data | research and education only |
| EgoBlind question and answer text in review exports and cache comparisons | `results/egoblind/**/review_events_*.csv`, `results/egoblind/**/cache_comparison_*.md` | CC BY-NC 4.0 (EgoBlind annotations) | non-commercial; cite Xiao et al., "EgoBlind: Towards Egocentric Visual Assistance for the Blind", NeurIPS 2025 Datasets and Benchmarks Track (https://github.com/doc-doc/EgoBlind), and attribute the original video sources, listed at https://drive.google.com/file/d/1Wob42tJ95DL1VvKad7BPc5QIlHtiuttI/view (EgoBlind's video source list; `scripts/download_egoblind.py` saves it to `data/egoblind/meta/video_source.csv`, which is not in git): that link must go with any redistribution |
| GuideDog evaluation results | `results/guidedog/` | derived from GuideDog (CC BY-NC 4.0, gated) | aggregate metrics and counts only, no GuideDog text or images; cite GuideDog |
| CampusBench scenarios, CampusBench-trained schedulers and their web export, `configs/pcacs_tuned.yaml` | `data/campus*`, `models/scheduler`, `models/arch_*`, `web/public/models/scheduler_rl.onnx` | generated by this repository | no third-party restriction |

## Used at run time, not shipped

| component | licence | note |
|---|---|---|
| Ultralytics package, YOLO-World weights (`yolov8s-worldv2.pt`) | AGPL-3.0 (YOLO-World upstream GPL-3.0) | open-vocabulary caches (`data/egoblind/cache_ow`) |
| CLIP ViT-B/32 (via the Ultralytics `clip` fork) | OpenAI model card (deployed use out of scope); package AGPL-3.0 | YOLO-World text encoder and the label-free indoor/outdoor scene classifier |
| Depth Anything V2 Metric Indoor Small | Apache-2.0, fine-tuned on Hypersim (CC BY-SA 3.0) | commercial use possible with attribution |
| Depth Anything V2 Metric Outdoor Small | Apache-2.0 tag, fine-tuned on Virtual KITTI 2 (non-commercial) | treat as non-commercial |
| EasyOCR | Apache-2.0 | sign reading |
| Kokoro-82M v1.0 (hexgrad), run with kokoro-js 1.2.1 | Apache-2.0 | the recorded voice pack `web/public/voice/af_heart/` (voice `af_heart`), generated offline by `web/voice/build.mjs`; the model itself is not shipped |
| ElevenLabs API | ElevenLabs terms (commercial use needs a paid plan) | optional voice |
| Vosk (`vosk` package and `vosk-model-small-en-us-0.15`), sounddevice (PortAudio) | Apache-2.0; MIT | offline voice commands in `make live`; installed by `make voice-setup`, model in `models/vosk/` (not in git) |
| Browser speech recognition (Web Speech API) | the browser vendor's terms | hands-free voice in the web app, off until the user turns it on; Chrome sends the audio to Google's speech service |

Datasets on disk (EgoBlind, GuideDog, TIMELI, VizWiz-Classification, Mendeley, BLV-Road-Nav, DADA-2000 annotations) are
not in git; their licences are in `docs/datasets.md`. GuideDog's gate terms forbid redistributing the data or data
derived from it.
